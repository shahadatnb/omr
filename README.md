# Admission Challenge — OMR Recognition Engine & Dashboard

এই প্রজেক্টটি একটি উচ্চ-নির্ভুল OMR (Optical Mark Recognition) ইঞ্জিন এবং ওয়েব ড্যাশবোর্ড যা Laravel 7 Admission Challenge প্রজেক্টের সাথে সম্পূর্ণ সমন্বিত।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ

1. **স্বয়ংক্রিয় Perspective Transform**: শিটের ৪টি কোণার কালো মার্কার (■) স্বয়ংক্রিয়ভাবে শনাক্ত করে বাঁকা বা কোণাকুণি স্ক্যান করা শিট সোজা করে।
2. **রেজিস্ট্রেশন নম্বর এক্সট্র্যাকশন**: 
   - শিটের ৬ ডিজিটের বাবল গ্রিড থেকে সংখ্যা পড়ে।
   - লারাভেলের `reg_no` (যেমন: `C-264003` বা `A-1`) থেকে বর্ণমালা ও হাইফেন বাদ দিয়ে শুধু সংখ্যা নিয়ে স্বয়ংক্রিয়ভাবে শিক্ষার্থীর সাথে ম্যাচ করে।
3. **মাল্টিপল সেট (A, B, C, D)**: সেট বাবল শনাক্ত করে লারাভেলে সেভ করা নির্দিষ্ট সেটের Answer Key অনুযায়ী নেগেটিভ মার্কিং সহ স্কোর হিসাব করে।
4. **ফোল্ডার আকারে ব্যাচ প্রসেসিং**: স্ক্যানার থেকে আসা সম্পূর্ণ ফোল্ডার বা একাধিক ফাইল একসাথে আপলোড ও প্রসেস করা যায়।
5. **ম্যানুয়াল এডিট বাটন (Unmatched Handle)**:
   - কোনো শিটের রোল নম্বর লারাভেলে ম্যাচ না করলে বা শিক্ষার্থী ভুল রোল ভরাট করলে **"ম্যানুয়াল এডিট"** বাটনে ক্লিক করে সংশ্লিষ্ট ক্লাস টেস্টের শিক্ষার্থী ড্রপডাউন থেকে সিলেক্ট করা যায়।
   - সেট বা রোল পরিবর্তন করলে স্বয়ংক্রিয়ভাবে পুনর্মূল্যায়ন হয়ে যায়।
6. **এক ক্লিকে লারাভেলে রেজাল্ট সিঙ্ক**: সকল ম্যাচড ও ম্যানুয়ালি এডিট করা শিটের নম্বর সরাসরি লারাভেলের `class_test_items` টেবিলে সিঙ্ক হয়ে যায়।

## 🚀 কীভাবে চালু করবেন

### ১. লারাভেল প্রজেক্ট চালু রাখা
নিশ্চিত করুন লারাভেল লোকাল সার্ভার চালু আছে:
```bash
cd D:\laragon\www\laravel-7-admissionchalange
# Laragon-এর Apache চালু থাকলে অথবা:
php artisan serve
```
- লারাভেলে Answer Key দিতে: `admin/classTest` এ গিয়ে সংশ্লিষ্ট পরীক্ষার পাশের **"Key"** বাটনে ক্লিক করে A/B/C/D সেটের সঠিক উত্তর সংরক্ষণ করুন।

### ২. OMR Django ড্যাশবোর্ড চালু করা
```bash
cd d:\python\omr
python manage.py runserver 8080
```
ব্রাউজারে ওপেন করুন: `http://127.0.0.1:8080/`
